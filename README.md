# Xora Landing Page 🚀

**Xora** is a modern landing page for a SaaS platform, featuring smooth animations and responsive design. Built with **React 19**, **Vite**, and **Tailwind CSS**, it demonstrates modern web development practices for startup landing pages.

## 🌐 Live Demo

Check out the live version of the site here:  
🔗 [https://xora-demo.netlify.app](https://xora-demo.netlify.app)

---

## 🛠️ Technologies Used

- **React** (v19) – UI library for building fast, component-based interfaces.
- **Vite** (v6) – Lightning-fast build tool and dev server.
- **Tailwind CSS** (v3.4.17) – Utility-first CSS framework for rapid styling.
- **React CountUp** – For animating numeric counters.
- **React Scroll** – Smooth scrolling between sections.
- **React SlideDown** – Animated collapsible dropdown sections.
- **clsx** – A tiny utility for conditionally joining classNames.

## ⚙️ Getting Started

Follow the steps below to run the project locally:

### 1. Clone the repository

```bash
git clone https://github.com/MukulTiwari02/Xora-landing-page.git
cd Xora-landing-page
```

### 2. Install dependencies

```bash
npm install
# or
yarn install
```

### 3. Start the development server

```bash
npm run dev
# or
yarn dev
```

Open your browser at `http://localhost:5173` (default Vite port) to view the app.

## 🎨 Customization

- **Styling**: Tailwind CSS classes allow you to easily customize colors, layout, and typography.
- **Content**: Update text and sections inside `components/` and `sections/` to match your brand.
- **Colors**: Adjust theme colors in Tailwind config.
- **Assets**: Replace placeholder images or SVGs in the `public/images` folder.

## 📂 Folder Structure

```
Xora-landing-page/
├── public/images/     # Static images and icons

├── sections/          # Page sections (e.g., Hero, Features)

├── tailwind.config.js # Tailwind config
├── postcss.config.js  # Postcss config file
└── vite.config.js     # Vite config
```
